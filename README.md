# 🚀 チャットツール開発チェックリスト

### 【P0】最優先：基本サイクル・セキュリティ
- [ ] **リフレッシュトークン**：JWTの自動更新（再ログインの手間を解消）
- [ ] **ログアウト機能**：セッションの破棄とトークン削除の実装
- [ ] **入力バリデーション**：フロント/バック両面での検証強化
- [ ] **チャンネルへの参加/退出**：ユーザーが自発的に参加・脱退できる仕組み
- [ ] **パスワード変更**：ログイン後のセキュリティ設定
- [ ] **ページネーション**：大量メッセージの無限スクロール対応

### 【P1】優先：利便性・コミュニケーション
- [ ] **メッセージ編集**：送信済みメッセージの内容変更
- [ ] **メッセージ検索**：キーワードによる全文検索
- [ ] **DM（ダイレクトメッセージ）機能**：1対1およびグループでのプライベート会話
- [ ] **スレッド返信**：メッセージに対するスレッド形式の返信
- [ ] **メンション（@mention）**：特定ユーザーへの通知付き言及
- [ ] **プライベートチャンネル**：招待されたユーザーのみ参加可能な部屋
- [ ] **ワークスペースメンバー一覧**：所属メンバーの閲覧・管理画面
- [ ] **通知設定**：チャンネルごとの通知オン/オフ切り替え

### 【P2】普通：UI/UX・拡張性
- [ ] **リアクション（絵文字）**：メッセージへのクイックレスポンス
- [ ] **メッセージの既読管理**：未読件数の把握と表示
- [ ] **オンライン/オフラインステータス**：ユーザーのアクティブ状態表示
- [ ] **ファイルストレージの外部化**：S3等への移行（ローカル保存からの脱却）
- [ ] **ワークスペース招待**：URLやメールによる参加リクエスト/招待リンク
- [ ] **メンバーのロール管理**：管理者・一般メンバーなどの権限制御
- [ ] **チャンネル編集**：チャンネル名や説明の動的な変更

### 【P3】低：仕上げ
- [ ] **プッシュ/ブラウザ通知**：メッセージ受信時のリアルタイム通知
- [ ] **カスタムステータス**：「会議中」などの独自ステータス設定
- [ ] **ワークスペースアイコン**：組織のサムネイル設定
- [ ] **アカウント削除**：ユーザー退会フローの整備
